Slide 06 • Stage 2 Deep-Dive

Classical Forensic Auditing Suite

Statistical conformity testing and account-level anomaly quantification
1. Benford's Law (First & Second Digits)Statistical Test

Evaluates digit probabilities in multi-order financial figures:

P(d) = log10(1 + 1/d), d ∈ {1, ..., 9}
MAD = (1/K) · Σ |Observed_i - Expected_i|
MAD < 0.006: Close Conformity
0.006 – 0.012: Acceptable Conformity
MAD ≥ 0.015: Nonconforming / Tampered

Chi-Square test (ν = 8 degrees of freedom) validates p-value significance.

2. Relative Size Factor (RSF)Outlier Ratio

Flags single disproportionate transactions relative to an account's normal activity:

RSF_i = Max(Amount_i) / Second_Max(Amount_i)
RSF < 2.5: Normal Spending Profile
2.5 – 5.0: Moderate Size Anomaly
RSF > 5.0: Severe Outlier (Capital Siphon)

Normalizes to a 0–100 risk score based on percentile rank.

3. Duplicate Transaction Clustered WindowsSmurfing Split

Identifies identical transaction amounts originating from the same sender within a rolling 24-hour interval, signaling automated split distribution.

4. Transaction Velocity Burst EngineBurst Spikes

Calculates rolling transaction frequency and total volume surges against an account's historical 30-day mean (velocity ratio > 3.5× flags an alert).

Presenter Note
Benford's Law detects macroscopic fraud across distributions, while RSF pinpoints micro-level account anomalies where a single payment dwarfs normal history.
Slide 07 • Stage 2 Heuristics

Forensic Typology Heuristic Engine

Algorithmic implementation of the four major international money laundering typologies
1. Structuring / Smurfing

Deliberately breaking large sums into sub-threshold payments to evade Mandatory Currency Transaction Reports (CTR).

Amount ∈ [0.88 · Threshold, Threshold) = [$8,800, $9,999.99]

Assigns an 85.0 forensic severity flag to structured transactions.

2. Fan-In (Consolidation Hubs)

Funnel accounts where multiple unique senders transfer funds into a single centralized beneficiary account within a tight window.

Unique Senders to Single Receiver ≥ 3 within rolling window

High indicator of illicit collection points or illicit retail fronts.

3. Fan-Out (Dispersal Nodes)

A single account rapidly disperses incoming capital out to numerous unique receiving accounts.

Unique Receivers from Single Sender ≥ 3 within rolling window

Typical signature of money mule network payrolls or integration.

4. Rapid Layering (Pass-Through)

Intermediary "conduit" accounts holding negligible opening balances, receiving and immediately forwarding identical sums.

|Inflow_Total - Outflow_Total| / Inflow_Total < 0.10 within 48h

Zero commercial retention indicates a deliberate obfuscation hop.

Presenter Note
These four heuristics reflect the FATF primary typology classifications. Our algorithms flag both the specific transaction and the coordinating network accounts.

Isolation Forest (Unsupervised)Zero-Day Anomaly

Recursive random binary space partitioning. Outliers require significantly fewer splits to isolate in terminal nodes:

s(x, n) = 2^(- E(h(x)) / c(n))

c(n) = 2(ln(n-1) + 0.5772) - 2(n-1)/n represents average BST path length.

S_IF = Min(100, Max(0, (Score_raw - Min) / (Max - Min) · 100))

✓ Operates without historical ground truth labels. Detects novel uncatalogued evasion techniques.

Presenter Note
Isolation Forest is essential because criminals constantly invent new laundering topologies that supervised models trained on past data have never seen before.

Iteratively optimizes regularized objective function at step t:

L^(t) = Σ l(y_i, y_hat^(t-1) + f_t(x_i)) + γ·T + (1/2)λ·Σ w_j^2

Slide 10 • Stage 4 Innovation

Multi-Pillar Composite Risk Scoring Formulation

Mathematical synthesis of deterministic forensics and machine learning with dynamic redistribution
Mathematical SynthesisFormulation

Baseline multi-pillar weighting:

S_composite = 0.40·S_forensic + 0.30·S_iso_forest + 0.30·S_xgboost

Dynamic Proportional Redistribution:

w_k* = w_k / Σ_{j ∈ A} w_j, where Σ w_k* = 1.0

When labels are missing (XGBoost inactive):
w_forensic* = 0.40 / 0.70 ≈ 57.14%
w_iso_forest* = 0.30 / 0.70 ≈ 42.86%
